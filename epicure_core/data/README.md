# epicure_core.data — Canonical Vocabulary Artifacts (v0.1)

This directory holds the canonical ingredient and compound vocabulary used
across the Epicure Suite. Generated by `python -m epicure_core.data.build_vocab`.

## Files

- `ingredients.parquet` — Canonical English ingredient names (v0.1: RecipeNLG-derived only).
  Schema: `canonical_name (str), language (str), aliases (list[str]), source (str)`.
  v0.1 aliases column is always `[]`; populated in v0.2 from multilingual sources.

- `compounds.parquet` — FlavorDB compound table (cleaned).

- `_staging/` — Raw downloaded artifacts. Gitignored. Regenerated by `--stage pull`.

## Deferred to v0.2: XiaChuFang, Povarenok, Tarladalal, Cookpad, Recetas, Yemek, Chefkoch

These 7 multilingual recipe corpora are listed in the PRD prose plan but
deferred from v0.1 to keep the data pipeline scope tight. When they land,
the `aliases` column populates with cross-language synonyms (e.g.,
`canonical_name="garlic", aliases=["ajo", "Knoblauch", "nasu", ...]`).

## Regenerating

Full pipeline (network + ~30 min on Pi 5):

```bash
python -m epicure_core.data.build_vocab --stage pull
python -m epicure_core.data.build_vocab --stage emit
```

The emit stage requires the bge-m3 ONNX model (downloaded automatically by
`epicure_core.embeddings` on first call).
