# Lean SD Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a lean, pre-baked `pantryatlas-vX.img.xz` (built non-destructively on robot via `sdm`) that boots a Pi 5 headless and serves the PWA at `http://pantryatlas.local` offline — core type→recipes flow working, LLM opt-in.

**Architecture:** Testable Python core in `pantryatlas/ops/image_build.py` (nftables ruleset, units list, image manifest) following the `db_publish.py` pattern; thin bash + an `sdm` plugin own the image plumbing. `sdm` handles rootfs resize/shrink, Bookworm first-boot suppression, and service-enable; our plugin bakes the PantryAtlas payload. A `pi_integration` chroot smoke-test is the no-hardware acceptance gate.

**Tech Stack:** Python 3.11 (stdlib), bash, `sdm` (github.com/gitbls/sdm), `nftables`, `avahi-daemon`, Cloudflare R2 via `wrangler`, pytest.

**Spec:** `docs/superpowers/specs/2026-05-28-sd-image-design.md`

**Branch:** `feat/sd-image`, stacked on `feat/hosted-recipe-db` (reuses `ops/lib/fetch.sh` `fetch_verified` and `pantryatlas/ops/db_publish.py::sha256_file`).

```python
"""Pure helpers for building the PantryAtlas SD image artifact.

Testable building blocks used by ops/image/build-image.sh and
ops/release/publish-image.sh:
- UNITS_TO_ENABLE   : the lean service set (no Gemma)
- nftables_ruleset  : the port-80 -> navigator redirect config
- build_image_manifest : assemble the release manifest dict

CLI (python -m pantryatlas.ops.image_build) writes per-version + latest image
manifests given the input shas. Mirrors pantryatlas.ops.db_publish.
"""

from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any

from pantryatlas.ops.db_publish import sha256_file

DEFAULT_IMG_BASE_URL = "https://dl.pantryatlas.org/img"

# Lean image: core services only. The LLM (pantryatlas-gemma) is intentionally
# excluded — vision stays opt-in (503-graceful).
UNITS_TO_ENABLE = [
    "pantryatlas-mem-monitor",
    "pantryatlas-embeddings",
    "pantryatlas-navigator",
]


def nftables_ruleset(*, dport: int = 80, to_port: int = 8090) -> str:
    """nftables config redirecting <dport> to the navigator on <to_port>.

    Covers both external clients (prerouting) and on-device localhost (output).
    """
    return f"""#!/usr/sbin/nft -f
flush ruleset
table ip pantryatlas_nat {{
    chain prerouting {{
        type nat hook prerouting priority dstnat; policy accept;
        tcp dport {dport} redirect to :{to_port}
    }}
    chain output {{
        type nat hook output priority -100; policy accept;
        ip daddr 127.0.0.0/8 tcp dport {dport} redirect to :{to_port}
    }}
}}
"""


def build_image_manifest(
    *,
    image_version: str,
    base_image: str,
    base_image_sha256: str,
    recipes_db_sha256: str,
    bge_m3_sha256: str,
    pantryatlas_commit: str,
    sha256: str,
    bytes_: int,
    built_at: str,
    base_url: str = DEFAULT_IMG_BASE_URL,
) -> dict[str, Any]:
    return {
        "image_version": image_version,
        "base_image": base_image,
        "base_image_sha256": base_image_sha256,
        "recipes_db_sha256": recipes_db_sha256,
        "bge_m3_sha256": bge_m3_sha256,
        "pantryatlas_commit": pantryatlas_commit,
        "url": f"{base_url}/pantryatlas-{image_version}.img.xz",
        "sha256": sha256,
        "bytes": bytes_,
        "built_at": built_at,
    }
```

```python
def main() -> None:
    parser = argparse.ArgumentParser(prog="pantryatlas.ops.image_build")
    parser.add_argument("--image", type=Path, required=True, help="Path to .img.xz")
    parser.add_argument("--version", required=True, help="Image version, e.g. v0.2.0")
    parser.add_argument("--base-image", required=True)
    parser.add_argument("--base-image-sha256", required=True)
    parser.add_argument("--recipes-db-sha256", required=True)
    parser.add_argument("--bge-m3-sha256", required=True)
    parser.add_argument("--pantryatlas-commit", required=True)
    parser.add_argument("--built-at", required=True, help="ISO-8601 UTC")
    parser.add_argument("--base-url", default=DEFAULT_IMG_BASE_URL)
    parser.add_argument("--out-dir", type=Path, required=True)
    args = parser.parse_args()

    if not args.image.exists():
        parser.error(f"image not found: {args.image}")

    manifest = build_image_manifest(
        image_version=args.version,
        base_image=args.base_image,
        base_image_sha256=args.base_image_sha256,
        recipes_db_sha256=args.recipes_db_sha256,
        bge_m3_sha256=args.bge_m3_sha256,
        pantryatlas_commit=args.pantryatlas_commit,
        sha256=sha256_file(args.image),
        bytes_=args.image.stat().st_size,
        built_at=args.built_at,
        base_url=args.base_url,
    )

    args.out_dir.mkdir(parents=True, exist_ok=True)
    body = json.dumps(manifest, indent=2) + "\n"
    (args.out_dir / f"pantryatlas-{args.version}.json").write_text(body)
    (args.out_dir / "pantryatlas-latest.json").write_text(body)

    print(f'IMAGE_URL="{manifest["url"]}"')
    print(f'IMAGE_SHA256="{manifest["sha256"]}"')


if __name__ == "__main__":
    main()
```

```bash
#!/usr/bin/env bash
# Publish a built SD image + manifests to Cloudflare R2.
#
#   ops/release/publish-image.sh <img.xz> <version> <manifest-dir>
#
# <manifest-dir> contains pantryatlas-<version>.json + pantryatlas-latest.json
# (produced by `python -m pantryatlas.ops.image_build` during the build).
#
# Env:
#   PUBLISH_DRY_RUN=1        skip wrangler uploads; print what would be uploaded
#   PANTRYATLAS_R2_BUCKET    bucket name (default: pantryatlas-artifacts)
set -euo pipefail

IMG="${1:?usage: publish-image.sh <img.xz> <version> <manifest-dir>}"
VERSION="${2:?usage: publish-image.sh <img.xz> <version> <manifest-dir>}"
MANIFEST_DIR="${3:?usage: publish-image.sh <img.xz> <version> <manifest-dir>}"
BUCKET="${PANTRYATLAS_R2_BUCKET:-pantryatlas-artifacts}"

put() {  # put <key> <file>
    if [ "${PUBLISH_DRY_RUN:-0}" = "1" ]; then
        echo "[dry-run] would upload $2 -> $BUCKET/$1"
    else
        npx -y wrangler r2 object put "$BUCKET/$1" --file "$2" --remote
    fi
}

put "img/pantryatlas-$VERSION.img.xz" "$IMG"
put "img/pantryatlas-$VERSION.json"   "$MANIFEST_DIR/pantryatlas-$VERSION.json"
put "img/pantryatlas-latest.json"     "$MANIFEST_DIR/pantryatlas-latest.json"

echo "[publish-image] done."
```

Make executable: `chmod +x ops/release/publish-image.sh`.

```bash
#!/usr/bin/env bash
# Stage the baked payload (recipe DB, embedding model, built web UI) into a dir
# the sdm plugin copies into the image.
#
#   ops/image/stage-payload.sh <stage-dir>
#
# Env:
#   PANTRYATLAS_DATA_DIR   (default ~/.pantryatlas)        — holds recipes.db
#   PANTRYATLAS_CACHE_DIR  (default ~/.cache/pantryatlas)  — holds bge-m3/
set -euo pipefail

STAGE="${1:?usage: stage-payload.sh <stage-dir>}"
DATA_DIR="${PANTRYATLAS_DATA_DIR:-$HOME/.pantryatlas}"
CACHE_DIR="${PANTRYATLAS_CACHE_DIR:-$HOME/.cache/pantryatlas}"
REPO_ROOT="$(cd "$(dirname "$0")/../.." && pwd)"

DB="$DATA_DIR/recipes.db"
MODEL="$CACHE_DIR/bge-m3"
WEB_DIST="$REPO_ROOT/web/dist"

[ -f "$DB" ] || { echo "ERROR: missing recipes.db at $DB (run the ingest first)" >&2; exit 1; }
[ -d "$MODEL" ] || { echo "ERROR: missing bge-m3 model at $MODEL (run embeddings once)" >&2; exit 1; }

mkdir -p "$STAGE"
cp -a "$DB" "$STAGE/recipes.db"
cp -a "$MODEL" "$STAGE/bge-m3"
if [ -d "$WEB_DIST" ] && [ -n "$(ls -A "$WEB_DIST" 2>/dev/null)" ]; then
    cp -a "$WEB_DIST" "$STAGE/web-dist"
else
    echo "WARN: $WEB_DIST empty — run 'npm --prefix web run build' before the real image build" >&2
fi
echo "[stage-payload] staged into $STAGE"
```
